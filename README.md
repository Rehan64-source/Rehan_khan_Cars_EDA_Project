# Cars Exploratory Data Analysis (EDA)

This project performs Exploratory Data Analysis on a used cars dataset. The goal is to identify pricing patterns, analyze vehicle depreciation, and find relationships between features like mileage, transmission type, and fuel type.

### Files Included:
* **Jupyter Notebook (.ipynb):** Contains the Python code for data cleaning, descriptive statistics, and data visualization.
* **PDF Report:** Contains the visual charts, observations, and top 5 key findings.
* **Dataset (.csv):** The raw data used for the analysis.
